### Modelo de dados

```json
{
  "pagamento": {
    "forma": "pix",
    "status": "pendente",
    "valor": 28
  }
}
```

Formas validas:

- `pix`
- `dinheiro`
- `cartao_credito`
- `cartao_debito`

Status validos:

- `pendente`
- `confirmado`
- `recusado`
- `cancelado`

### Regras implementadas

- Pedido valido exige forma de pagamento habilitada na loja.
- O valor do pagamento e sempre derivado do total calculado no servidor.
- Valor manipulado enviado pelo frontend e rejeitado.
- Status inicial do pagamento e sempre `pendente`.
- Cliente nao pode confirmar pagamento.
- Apenas admin da mesma loja pode confirmar, recusar ou cancelar pagamento.
- Admin de outra loja e bloqueado.
- Pedido cancelado nao permite atualizacao financeira.
- Transicoes invalidas de status financeiro sao rejeitadas.
- Dados sensiveis de cartao, senha ou token sao rejeitados.
- O status financeiro fica separado do status operacional do pedido.
